1. Software Features

TL;DRAPM and PM Platform manage properties, leases, tenants, work orders, messages, calls, documents, invoices, rent status, and reports. Rent collection, reconciliation, property-expense reporting, and accounting tools are capability-gated; Harry must check the signed-in account before describing them as available.

APM and PM Platform help a landlord manage rental property units from one operating system. The product combines the web dashboard, native APM app, tenant portal, dedicated phone/SMS communication, documents, leases, work orders, contacts, vendors, invoices, property expense tracking, and operational reports.

The core goal is simple: give landlords and tenants one clear place to communicate and one shared record for day-to-day property operations.

Dashboard

The web dashboard is the main office view. Its current navigation is Today, Properties, Rent & Leases, Maintenance, Money, Inbox, Files, Contacts, and Settings. Use it for onboarding, bulk imports, detailed editing, lease documents, transactions when enabled, invoice review, documents, reports, and account settings.

APM Mobile App

The APM app is the field and communication view. Its main tabs are Today, Money, Inbox, Properties, and More. More opens Maintenance, Contacts, Reports, Invoices, Settings, and About. Use APM for calls, messages, work orders, property detail, rent status when enabled, invoice capture and approval, reports, and tenant/vendor communication.

Tenant Portal

Tenants get a lease-specific portal link where they can report and review work orders, message the landlord, view lease documents, request lease changes, request move-out, and review rent ledger/payment history when the portal rent capability is enabled.

Communication Hub

A dedicated Twilio phone number can receive tenant SMS, outbound landlord SMS, inbound calls, voicemail, and app calls. Known tenant calls can be routed through an automated menu before ringing the landlord.

Harry Assistant

Harry is the screen-aware in-product assistant. The launcher appears on both the dashboard and APM. Harry suggests next steps based on the current screen, explains features, and can navigate the user to the right place. See the Harry Assistant section.

2. User Roles And Access

TL;DRThe current application roles are landlord, owner read-only, and internal admin. Tenants use lease-specific portal links. There is not yet a configurable property-manager/team-member role in the landlord UI.

Access controls depend on the signed-in role and account capabilities. The current code supports these user types.

Role Typical Access Notes
Landlord / account holder Full portfolio operations, setup, properties, leases, work orders, messages, documents, reports, settings. This is the main user who completes onboarding and installs APM.
Owner / read-only viewer Read-only owner experience. Dashboard navigation hides transactions, rent status, reports, settings, inbox, contacts, leases, and lease generator. Owner accounts are provisioned by an admin and should not change operational records.
Internal admin Administrative support and account-management tools. This is an internal role, not a landlord-configurable team seat.
Tenant Tenant portal only: messages, maintenance requests, lease documents, move-out/change requests. Tenant portal links are lease-specific and should only be shared with the correct tenant.

3. Quickstart

TL;DRCreate account → open the automatic Sandbox tour → switch to Production when ready → finish Company Setup, Properties, and Review → configure Phone & Calls and Invoice Intake in Settings → verify with a test tenant before real communication.

If you are setting up a new landlord account, follow this order.

  1. Create or accept your account. Use the invite/register link, then sign in to the web dashboard.
  2. Start in Sandbox. First-time users are started in Sandbox mode with sample data so they can try the app, reports, work orders, messages, and settings without entering real portfolio data.
  3. Switch to Production when ready. Use the mode control, then complete the three production onboarding steps: Company Setup, Properties, and Review.
  4. Review imported leases. Confirm property address, tenant name, rent, deposit, lease start/end, city/state, phone, and LLC assignment before saving.
  5. Activate communication after onboarding. Open Dashboard > Settings > Phone & Calls, choose the local area code, request the business number, review the welcome SMS, and save call routing.
  6. Install APM. Use the dashboard install card for iOS TestFlight or Android beta, then sign in with text code, password, Google, or the dashboard app handoff.
  7. Configure phone behavior. In APM, open Settings > Calls and choose Ring this app, Forward to my phone, or App first, then forward. Dashboard Settings contains the additional tenant-menu and quiet-time controls.
  8. Configure invoice intake. Open Dashboard > Settings > Invoice Intake to review the shared intake address and register every sender email. The Invoices pages also display the intake address.
  9. Invite tenants or send welcome texts. Send tenant portal links and welcome SMS only after the lease data, phone number, and message template are correct.
  10. Run the daily workflow. Use APM Today and Inbox, Money for rent/invoices/reports, More > Maintenance for repairs, and Property Detail for lease/unit records.
  11. Meet Harry. Open the dashboard launcher or the Harry header button on a supported APM screen. Ask "What should I do next?" for screen-aware suggestions.
Recommended first test: Before texting real tenants, create or use a test tenant/lease, send yourself a welcome message, open the tenant portal, submit a work order, reply from APM, and confirm the record appears on both the Dashboard and APM.
Mode reminder: Switch between Sandbox and Production from the dashboard mode control or APM Settings > Account. Sandbox is for learning and demos. Production is for real tenants, properties, calls, leases, and invoices.

4. Onboarding Overview

TL;DRFirst-time accounts open a Sandbox tour automatically. Production onboarding has three screens: Company Setup → Properties → Review. Phone and invoice configuration happen later in Settings.

The dashboard first opens a temporary sample Sandbox so a new user can tour the product without touching production records. When the user switches to Production, an incomplete landlord account is routed to the three-step onboarding wizard:

  1. Company Setup: operating states, LLC count, LLC details, management model, lease defaults.
  2. Properties: upload lease PDFs, import from software/CSV, add properties manually, or skip and add them later.
  3. Review: confirm the account setup and finish to the dashboard.
Communication is not an onboarding step: After production onboarding, use Dashboard > Settings > Phone & Calls to request the business number, configure tenant call routing, quiet times, and the welcome template. Use Settings > Invoice Intake to register sender emails.

What To Have Ready Before Starting

  • List of all rental properties and units.
  • Each LLC name, state, EIN if available, and legal mailing address.
  • Lease PDFs or a CSV export from Stessa, TurboTenant, Baselane, or another system.
  • Tenant names, phone numbers, and email addresses.
  • Preferred area code for the dedicated APM phone number.
  • The email addresses that will forward invoices or receipts into APM.

5. Set Up A Company

TL;DRDuring onboarding: pick operating states, enter each LLC/company, choose management model, and set starting lease defaults. After onboarding, edit company records in Dashboard > Settings > Profile & Companies.

Company setup tells the system which legal entities own the portfolio, which states are used for leases, and what defaults to apply when new leases are created.

During Onboarding

  1. Open the web dashboard and continue to the Company Setup screen.
  2. In Operating states, select every state where you manage rental units. If you operate in more than one state, choose the primary/default state.
  3. Enter the number of LLCs or ownership entities you use.
  4. For each LLC, enter the legal LLC name, state, EIN if available, and any requested company details.
  5. Choose the management model:
    • Self-managed: the landlord/account holder manages the portfolio directly.
    • Per LLC: each LLC can have its own management/signing information.
    • Per property: management may vary property by property.
  6. Select lease defaults. Choose fixed term or month-to-month, security deposit policy, and whether to track insurance now or later.
  7. Save or continue to the Import step.

Recommended Defaults

DefaultWhy It Is Preselected
Self-managed management modelMost beta landlords manage their own units first. This keeps setup simple and can be changed later if management differs by LLC or property.
Fixed-term lease when lease dates are foundUploaded leases usually include a start and end date. Month-to-month can be selected when the lease has no fixed expiration.
Security deposit equal to rentThis matches a common landlord pattern and fills faster. Change it when your lease uses a different deposit rule.
Track insurance laterLets users finish setup first, then add policy details from Settings or property detail when records are available.

After Onboarding: Edit Company Records

  1. Open Dashboard > Settings.
  2. Use Profile & Companies to review the account holder email, phone, LLC/company records, EINs, and legal addresses.
  3. If your mobile number is not verified, enter the phone number, request the verification code, then enter the 6-digit code.
  4. Update each company legal address or EIN if needed.
  5. Click Save Company Settings.

Configure Lease Signer Defaults

  1. Open Dashboard > Settings > Lease Defaults.
  2. Choose whether to use one global landlord/manager signer or per-LLC signer overrides.
  3. Enter default landlord/manager name, email, and phone.
  4. If using per-LLC overrides, enter the correct signer name, email, and phone for each LLC.
  5. Confirm enabled states and default state.
  6. Click Save Lease Settings.
Why this matters: Lease generation, addendums, tenant portal records, and reports all rely on correct company, LLC, state, and signer data.

6. Import Properties And Leases

TL;DRThree paths: upload lease PDFs, import CSV from Stessa/TurboTenant/Baselane/Other, or add rows manually. Review every extracted field before confirming.

The Import screen creates the starting portfolio. You can upload lease PDFs, import from a CSV/export, or add rows manually.

Option A: Upload Lease PDFs

  1. In onboarding, open the Import step and choose Upload Leases.
  2. Select one or more lease PDFs.
  3. Wait for extraction. The system reads the lease and suggests property address, tenant, rent, deposit, dates, city/state, unit, and contact details.
  4. Review every extracted field. Pay special attention to address, tenant legal name, phone, email, rent, lease start/end, deposit, and LLC.
  5. If city or state is missing, fill it manually. Zip lookup may suggest city/state when available.
  6. Correct low-confidence fields before continuing.
  7. Confirm the properties and leases.

Option B: Import From Software

  1. In the Import step, choose Import from Software.
  2. Select the source if known: Stessa, TurboTenant, Baselane, or Other. Auto-detect can be used if you are not sure.
  3. Upload the CSV export.
  4. Review mapped columns and imported rows.
  5. Correct any address, tenant, rent, or status errors.
  6. Confirm the import.

Option C: Add Manually

  1. In the Import step, choose Add Manually.
  2. Enter the street address, unit if applicable, tenant name, tenant phone, rent, zip, city, state, and LLC.
  3. Add one row per unit or lease.
  4. Confirm when the list is complete.

Add More Properties Later

  1. Open Dashboard > Settings > Imports & Setup.
  2. Choose Add Additional Properties.
  3. Select whether the properties belong to an existing LLC or a new LLC.
  4. Continue to the import flow and follow the same review steps.
Avoid duplicate leases: If you are replacing or re-importing data, use the Settings re-run setup options carefully. Add properties preserves existing records. Reimport may replace properties/tenants while keeping LLCs and phone number. Fresh deletes data and should only be used intentionally.

7. Set Up Communication And Twilio

TL;DRCommunication setup happens after onboarding. Open Dashboard > Settings > Phone & Calls to request and configure the dedicated number. In APM, open More > Settings > Calls for call handling and unknown-caller behavior.

The dedicated APM number supports tenant SMS, inbound calls, voicemail, and app calling. It is separate from the landlord's personal phone number and is not part of the current three-step onboarding wizard.

Request Or Review The Dedicated Number

  1. Finish the Company Setup, Properties, and Review onboarding steps.
  2. Open Dashboard > Settings > Phone & Calls.
  3. Review the dedicated number and provisioning status. If the account does not have a number, follow the request/provisioning control shown for the account.
  4. Review the tenant welcome template before sending messages. Supported template variables may include {tenant_name}, {landlord_name}, and {property_address}.
  5. If approval is required, wait for the status to become active before treating the number as ready.

Before You Text Tenants

  • Confirm tenant names and phone numbers are correct.
  • Confirm every tenant is attached to the correct property/unit/lease.
  • Confirm the welcome SMS says what you want.
  • Confirm the APM app is installed and signed in.
  • Confirm voice settings are configured in APM.
  • Send a test message to yourself first if possible.

Set Incoming Call Behavior

  1. Open Dashboard > Settings > Phone & Calls, or open APM > More > Settings > Calls.
  2. Confirm the dedicated APM phone number and provisioning status.
  3. Under How incoming calls are received, choose one:
    • Use Twilio app Default: calls ring in APM over VoIP. Preselected because it keeps tenant calls inside the APM communication record.
    • Forward to local number: calls forward to the configured phone number.
    • Twilio app, then local number if unanswered: APM rings first, then forwards if unanswered.
  4. Choose Unknown Caller Mode:
    • Screen: ask the caller to identify themselves before routing.
    • Voicemail: send unknown callers to voicemail.
    • Reject: reject unknown callers.
    • Allow: allow unknown callers through based on routing mode.
  5. Choose Tenant Calls:
    • Automated tenant menu Default: tenants hear approved menu options first. Preselected because it pushes maintenance and lease requests into the portal instead of scattered voicemail.
    • Ring APM / phone during open hours: tenant calls ring according to voice mode during open hours. Quiet times still play the outside-hours menu.
  6. Save the phone or call settings.

Tenant Call Menu

When a known tenant calls the dedicated number and tenant menu is enabled, APM plays one of the approved menu scripts. Landlords choose from preselected profiles; the menu text is not free-form editable because tenant-facing campaign language is controlled.

Menu ProfileTenant HearsWhy To Use It
Default Portal-first menuPress 1 for a tenant portal link, Press 2 to leave voicemail, Press 3 to hear options again.Best default. Sends maintenance, lease, and change requests into the tenant portal.
Portal plus connect optionPress 1 for a tenant portal link, Press 2 to leave voicemail, Press 3 to connect to the landlord.Use when you want tenants to self-serve first but still offer a direct connection.
Maintenance-focused menuPress 1 for a link to report maintenance or view the lease in the portal, Press 2 for voicemail, Press 3 to hear options again.Use when the phone number is primarily for maintenance intake.

Quiet Times

Default Tenant quiet times are enabled from 8:00 PM to 8:00 AM and apply on weekends. This protects the landlord from routine calls outside normal hours while still giving tenants a way to report maintenance, get their portal link, or leave a voicemail.

  1. Open Dashboard > Settings > Phone & Calls.
  2. Keep Enable tenant quiet times on unless you want tenant calls to ring at all hours.
  3. Adjust start time, end time, weekend behavior, or timezone if your operating schedule is different.
  4. During quiet time, tenants hear: "Hello [tenant], you've reached us outside normal hours..." followed by the selected approved menu options.

Decide Whether Tenants Can Ring The Phone

  1. If you want tenants to use the portal first, keep Automated tenant menu selected and use the Portal-first menu.
  2. If you want tenants to reach you directly during business hours, select Ring APM / phone during open hours, then choose whether calls ring APM, forward, or both.
  3. Keep quiet times enabled if routine tenant calls should not ring after hours.
  4. If you want emergency or favorite contacts to bypass do-not-disturb, use the routing controls on APM Home if available.
  5. If you want unknown callers screened, set Unknown Caller Mode to Screen.
  6. If you want unknown callers to leave a message only, set Unknown Caller Mode to Voicemail.
Shared setting: Dashboard > Settings > Phone & Calls and APM > Settings > Calls use the same account call configuration. A saved change should appear on the other surface after refresh.

8. Configure Invoice Intake

TL;DROpen Dashboard > Settings > Invoice Intake to see the intake address and manage approved senders. Forward invoices, upload in Dashboard > Money > Invoice intake, or use APM > More > Invoices. Review extracted fields before approval or routing.

Invoice intake lets landlords collect invoices and receipts by upload or email. The system scans PDF/image files, extracts vendor/amount/date/category/property, and holds drafts for review before routing them.

Time saver Email invoices instead of manually entering them. When you forward invoices to the intake email, APM scans them and places them in the invoice review queue already matched or suggested by vendor, property, category, amount, and date. You review and approve before anything is routed.

Find The Intake Email Address

  1. Open Dashboard > Settings > Invoice Intake.
  2. Copy the account's invoice intake email address.
  3. Use that address when forwarding invoices or setting mailbox forwarding rules.

Configure Authorized Senders And Aliases

Default The account holder email is normally authorized first because it is the safest starting point. Add additional authorized sender emails if invoices will come from a bookkeeper, owner, property manager, LLC inbox, vendor forwarding rule, or scanner service.

  1. List every email address that will forward invoices or receipts.
  2. Decide whether you need one shared intake alias or multiple aliases for different LLCs or workflows.
  3. Add or remove authorized senders in Settings > Invoice Intake. Do not assume an unlisted sender will be accepted.
  4. After an email is authorized, test by forwarding one simple invoice PDF and confirming it appears in the Invoices queue.
Example: The main landlord email can be authorized, and an additional address such as bookkeeping@example.com can also be authorized so the bookkeeper can forward invoices directly. A separate LLC inbox can also be authorized when invoices are received there.

Scan Or Upload An Invoice

  1. Open Dashboard > Money > Invoice intake.
  2. Click Upload from photos/files.
  3. Select a PDF or image.
  4. Review extracted vendor, total, date, invoice number, category, property, and work order if suggested.
  5. Check duplicate warnings before saving.
  6. Choose a route:
    • Save invoice only: stores the document and invoice record.
    • Create work order: creates or connects the invoice to maintenance work.
    • Track as operational expense: attaches the invoice to a property for expense reporting.
    • Archive: keeps it out of the active queue.

Use APM Invoice Scan

  1. Open APM > More > Invoices, APM Home, or the relevant property/work order screen.
  2. Tap the invoice scan/upload action.
  3. Take a photo or choose a file.
  4. Review extracted fields before confirming.
  5. Route the invoice to a work order, document-only record, operational expense, or archive.

11. Properties, Units, Tenants, And Leases

TL;DRProperty Detail combines property data, unit file, tenants, leases, work orders, messages, documents, photos, inspections, and operational expense snapshot.

Property Detail is the main record for a rental unit. It combines property data, unit file, tenants, leases, work orders, messages, documents, photos, inspections, and operational expense snapshot.

Open A Property

  1. Open Dashboard and click a property row/card, or open APM > Properties and tap a property.
  2. Confirm the address, city/state, LLC, occupancy, and unit information.
  3. Use Overview; People & Lease (Unit file, Messages); Operations (Work orders, Inspections); and Files (Documents, Photos).

Edit Property Details In Dashboard

  1. Open the property detail page.
  2. In Overview, find the Property Details section.
  3. Edit fields such as property type, bedrooms, square feet, assessed value, purchase data, loan/equity details, or insurance.
  4. Save the section.

Use The Unit File

  1. Open the property detail page.
  2. Open the Unit File tab.
  3. Record systems such as HVAC, water heater, roof, appliances, plumbing, electrical, and system notes.
  4. Add inspection schedule and reminders when needed.
  5. Save the unit file so future work orders and inspections have context.

Add Or Edit A Lease / Tenant In Dashboard

  1. Open the property detail page.
  2. Open People & Lease and use the supported lease create, edit, or terminate action.
  3. Enter tenant name, phone, email, monthly rent, lease start/end, lease type, deposit, rent due day, late fee amount/grace, status, past due, and pets.
  4. Save the lease.
  5. Confirm the property/unit occupancy updates and the tenant appears in Contacts and Messages.

Add Or Edit A Lease / Tenant In APM

  1. Open APM > Properties.
  2. Tap the property.
  3. Use Add / Edit Lease to create or update a lease, or Add Tenant to add tenant contact/lease information to an existing property.
  4. If the property is occupied and you are replacing the lease, APM asks whether the current tenants are moving out.
  5. If they are moving out, enter the current lease end or move-out date.
  6. Enter the new tenant name, phone, email, rent, deposit, rent due day, late grace days, late fee amount, lease type, start date, and end date if fixed term.
  7. Save and refresh. The change should appear in both APM and the web dashboard.

Terminate Or Replace A Lease

  1. Open the property in Dashboard or APM.
  2. Confirm whether the current lease is ending, the tenant is moving out, or you are only correcting data.
  3. If the lease is ending, enter the expiration/move-out date.
  4. Create the new lease only after the existing tenant status is clear.
  5. Confirm the old tenant is no longer active for the unit and the new tenant has the correct lease dates.
Use the lease replacement prompt carefully: If you say the current tenant is moving out, the system can mark the existing lease as ending. If you are only correcting a phone number or rent amount, edit the existing lease instead.

12. APM Property Detail Deep Dive

TL;DRProperty Detail has four segments: Overview, Lease & Tenant, Maintenance, and Money. Choose the segment first, then use the cards and actions inside it.

APM Property Detail is the mobile command center for one property. The four-segment layout replaces the older single page of many collapsible cards.

Overview

  • Property Profile: address, LLC/company, property type, bedrooms, bathrooms, square footage, and occupancy context.
  • Attention: important property items that need review.
  • Insurance & Compliance: carrier, policy, premium, dates, supporting documents, and compliance information.
  • Notes: internal property notes that are not shown to tenants.

Lease & Tenant

  • Units & Lease: unit occupancy, tenant details, active lease terms, and add/edit lease actions.
  • Tenant Portal: view, share, revoke, or restore the lease-specific link. Use the share action for SMS, email, or the system share sheet.
  • Documents: lease, addenda, inspections, and other files attached to the property or lease.
  • Communications: recent tenant messages and related communication history.

Use the lease actions to update the active lease or start supported renewal/addendum work. If a tenant is moving out, open the dedicated move-out inspection screen from the relevant property/lease action.

Maintenance

  • Open Maintenance: active work orders and their current status.
  • Systems: HVAC, water heater, roof, appliances, plumbing, electrical, and service context.
  • Inspections: scheduled and completed property inspections.
  • Reminders: dated property tasks that are not tied to a work order.
  • Maintenance History: completed and archived work orders for repeat-issue context.

Money

  • Rent Status: expected, received, outstanding, and lease ledger information when the account has rent operational capability.
  • Expense Snapshot: operational expenses from supported work-order and invoice records when property expense capability is enabled.
Capability check: A card can be absent because the account or property does not support it. Confirm account capabilities before telling a user that a missing card is an error.

13. Lease Generator And Approvals

TL;DROpen Dashboard > Leases > Lease Generator for new lease documents. For existing active leases, use Property Detail in Dashboard or APM to start a lease renewal or addendum. Native signing/approval can be sent by email or phone, and pending signatures appear in home follow-ups.

The lease tools help create lease documents, lease renewals, addendums, and approval/signing requests. Always confirm the legal and state-specific terms before sending a lease for approval.

26. Q&A

Each Q&A has a data-harry-link attribute on its <h3> so Harry can return a clickable link with the answer. Links target the dashboard route; APM has its own native routes for the same intent and Harry handles that internally.

How do I set up a new company?

In production onboarding, complete Company Setup, Properties, and Review. Select operating states, enter company/LLC details, choose the management model, and set starting lease defaults. After onboarding, use Dashboard > Settings > Profile & Companies and Lease Defaults to update EINs, legal addresses, signers, and default state.

How do I add a new property?

In APM, open Properties and use the add-property action for a single property. In Dashboard, use Settings > Imports & Setup > Add Additional Properties for lease PDF, CSV/software export, or manual entry. Review the address, company/LLC, tenant, rent, and lease dates before confirming.

How do I add a tenant to an existing property?

Open the property in Dashboard or APM. In Dashboard, open People & Lease and use the supported lease action. In APM, open Property Detail > Lease & Tenant and use Add Tenant or Add / Edit Lease. If the unit is occupied, confirm whether the current lease is ending and enter the move-out/expiration date when applicable.

How do I set up a new lease?

For a lease record, open the property and use New Lease or Add / Edit Lease. For a generated lease document, open Dashboard > Leases or Documents > Lease Generator, choose the property/unit, enter lease terms and tenant contacts, review, then generate/save or send the native signing packet. Tenants can sign with an email address or phone number. If you ask this in APM, Harry will offer to open the dashboard at the Lease Generator for you.

How do I renew a lease or create an addendum?

Open Property Detail in Dashboard or APM, choose the active unit/lease, then select Renewal or Addendum. For a renewal, confirm renewal rent, renewal start date, optional end date, and changed terms. For an addendum, choose the addendum type, effective date, and terms. Both use the built-in signing/approval flow and pending signatures appear in home follow-ups.

How do I send a saved lease to a tenant?

Open the lease record in Dashboard > Leases. Choose Email lease. Confirm the tenant email and the lease PDF attachment, then send.

How do I send tenants their portal link?

From APM Property Detail > Tenant Portal, use Share Link (SMS, email, or system share). From the dashboard, open the property detail page and use the tenant portal control. Known tenants can also call the dedicated number and press 1 to receive the portal link by SMS.

How do tenants report maintenance?

Tenants open their tenant portal and choose Maintenance Request, or open /work-orders/:token directly. They enter the issue, add details/photos, and submit. The landlord sees the request as a work order in APM and Dashboard.

How do tenants request move-out?

Tenants open /move-out/:token from the portal. They enter planned date, forwarding address, and notes, then submit. The landlord sees the request on the property/lease and can confirm the move-out date and open Property Detail > Move-Out Inspection to record condition.

How do I decide whether tenants can call me directly?

Open Dashboard > Settings > Phone & Calls or APM > More > Settings > Calls. Keep the automated tenant menu selected if tenants should self-serve first. Choose direct ringing during open hours if tenant calls should ring you. Quiet times default to 8 PM to 8 AM, including weekends, and play the outside-hours menu for routine calls.

How do I set up the Twilio number?

Communication is not a current onboarding step. Finish onboarding, then open Dashboard > Settings > Phone & Calls to request or review the dedicated number, provisioning status, welcome template, routing, and quiet times. Use APM > More > Settings > Calls for mobile call handling.

How do I add invoice emails?

Open Dashboard > Settings > Invoice Intake. Copy the intake address and add each owner, bookkeeper, company inbox, or forwarding address that is allowed to send invoices. Save the approved-sender list, then forward one simple invoice to verify it reaches the queue.

How do I scan an invoice?

Use Dashboard > Money > Invoice intake > Upload from photos/files, or open APM > More > Invoices and use its add/upload action. You can also email invoices from an approved sender. Review vendor, amount, date, property, category, and duplicate warnings before approval or routing.

Why did the app start in Sandbox?

Sandbox is the first-time default so new users can try the product with sample data before entering real properties or tenants. Switch to Production when you are ready for real setup. You can switch back to Sandbox later to practice.

Why do I not see rent payments or financial reports?

Those surfaces are capability-gated. Rent operations, provider reconciliation, bank reconciliation, financial accounting, property expense reports, and online payments are separate capabilities. Check the account capability response and required connection state; a missing item may be intentional. See Rent, Transactions, And Financial Capabilities.

How do I export a report from APM?

Open APM > More > Reports, select the report, apply Scope or Period when supported, tap Export, then choose PDF or Excel. Export controls and formats vary by report.

Where is the Schedule E report?

Open APM > More > Reports > Schedule E or Dashboard > Money > Reports > Schedule E. The report groups supported expense rows by LLC, property, and Schedule E line. Harry can explain where the report data comes from, but tax treatment and filing decisions should be reviewed with a CPA or tax professional.

How do I track property expenses?

Use supported work order actual costs and invoice intake to build the property expense record. In APM, open More > Reports > Property Expenses. In Dashboard, open Money > Reports > Property Expenses. This report appears only when the account has the property-report capability.

How do I review invoices needing approval?

Open APM > More > Invoices, or Dashboard > Money > Invoice intake. Review extracted fields and source documents, edit or route supported values, select one or many items, and use the available approval actions. Invoice approval is not under Reports.

Where do I see and edit my quick replies?

Open APM > More > Settings > Messaging > Quick Replies. Add a short title and body, save, then pick the reply from the message composer.

Where is the APM health check and error log?

Open APM > More > Settings > About > Advanced Diagnostics for health information. Open Help & Support > Error Log for recent client-side errors. Both are useful in a bug report.

How do I update APM?

Open APM > More > Settings > About and use the available OTA update control. If an update is available, follow the prompt. For full app upgrades, use the currently distributed iOS or Android channel.

How do I report a bug?

Use the APM feedback button or support channel. Include the screen, account mode, steps, expected result, actual result, property/tenant/work order if relevant, the most recent Error Log entry, and whether it blocks tenant communication or daily work.

How do I know if data changed in both APM and Dashboard?

After saving, refresh the other app surface and open the same property, lease, work order, or tenant. APM and Dashboard use the same backend records, so successful saves should appear in both places.

What can I ask Harry?

Anything inside the product: setup, properties, leases, lease renewals/addenda, tenants, work orders, messages, contacts, documents, invoice intake, property expenses, Schedule E report organization, operational reports, communication setup, tenant portal rollout, sandbox vs production, and bug reporting context. Harry will not give tax/legal/financial advice or answer general trivia.
